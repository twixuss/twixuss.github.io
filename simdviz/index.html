Intro

Array elements are shown in memory order, so 0 1 2 3, instead of intel's 3 2 1 0

One or more inputs are at the top, the output(s) - at the bottom.

Different inputs are spaced out and have different colors.

If destination value connects to multiple inputs - single input is selected based on value of an immediate / register.
Possible variants for a single value will be stacked vertically.

Dots are used to abbreviate long continuous ranges / repeating info.

If lanes are connected with a dashed white line - they are shuffled using the same control value.
