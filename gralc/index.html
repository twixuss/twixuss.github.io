GRALC - Graphing calculator. Made by twixuss.

Graphs

In one of the lines on the left, type an equation like x*x or x=sin(y) to see it graphed on a corresponding axis. If you use both x and y (or vec2 variable named p), the output will show a gradient, which increases in color intensity when the function increases. Or you can equate two expressions, like (sin(x) = sin(y)) (parens are needed so you don't create new `sin` function, which would conflict with the built-in). Then the gradients will not be shown, only roots of the equation. You can assign an output of a graph to a name by prepending name = , like a = x*x. You can use that name in other graphs. You can create functions by appending a list of parameters to a graph's name, e.g. f(x,a,b) = x*a + b. Until there is a better way, you can get a derivative of graph f by doing ddx(f)/ddx(x). You can limit the range of a graph/function by apppending [limitMin, limitMax]. It is limited though as it only applies to x of graphs and first parameters of functions. Custom limits can be done by setting the output to a huge value, e.g. like this: mix(f(x), 1e30, step(x, limitMin) + step(limitMax, x))

Sliders

Type name = number where name is any valid GLSL identifier and number is any integer/float literal. Instead of typing that, you can first write your graph that references not yet existing slider(s), and then there will be a button that creates the missing slider on click.

Unnamed section

You can comment your stuff with // this Your session will be automatically stored locally. You can save/share it somewhere by copying the url or pressing export button on the right, which does the same thing. Use of identifiers starting with underscore _ is not recommended as they might collide with internal variables. You can reorder lines by dragging the leftmost box.

Uniforms

iCamera.xy - Camera position: center of view in graph coordinates iCamera.z - Zoom level. Viewport height spans pow(2, iCamera.z) graph units. iCamera.w - X scale. E.g. value of 2 will squish everything so you see more. iTime/time - Seconds elapsed since the start

Builtin Functions

Both GLSL and HLSL function names are available. map(x,a,b,c,d) - maps x from range [a; b] to range [c; d] mapc(x,a,b,c,d) - additionally clamps x smin(a,b,k) - smooth minimum smax(a,b,k) - smooth maximum clamp01(x) sfloor(x, k) - smooth floor (without discontinuities) sfrac[t](x, k) - smooth fraction (without discontinuities) smoothstepP(a,b,x,d) - parametric smoothstep, constructed out of two pow(x, d) curves. d determines the slope at the middle. Has C1 continuity in the middle and C(d-1) continuity at the edges. logBase(base, x) sec(x) = 1.0/cos(x) - secant csc(x) = 1.0/sin(x) - cosecant
