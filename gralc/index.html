Graphs

Type an equation like x*x or x=sin(y) to see it graphed on a corresponding axis. If you use both x and y (or vec2 variable named p), the output will show a gradient, which increases in color intensity when the function increases. Or you can equate two expressions, like sin(x) = sin(y). Then the gradients will not be shown, only roots of the equation. You can assign an output of a graph to a name by prepending name = , like a = x*x. You can use that name in next graphs. Until there is a better way, you can get a derivative of a graph f(x) by doing ddx(f(x))/ddx(x).

Sliders

Type name = number where name is any valid GLSL identifier and number is any integer/float literal.

Uniforms

iCamera.xy - Camera position: center of view in graph coordinates iCamera.z - Zoom level. Viewport height spans pow(2, iCamera.z) graph units. iTime - Seconds elapsed since the start

Functions

Both GLSL and HLSL function names are available. map(x,a,b,c,d) - maps x from range [a; b] to range [c; d] mapc(x,a,b,c,d) - additionally clamps x smin(a,b,k) - smooth minimum smax(a,b,k) - smooth maximum clamp01(x) sfloor(x, k) - smooth floor (without discontinuities) sfrac[t](x, k) - smooth fraction (without discontinuities)

Constants

pi tau phi
